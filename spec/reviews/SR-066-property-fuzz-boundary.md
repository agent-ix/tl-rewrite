# Evidence review — rewrite property fuzz boundary

## Summary

Applied the Quoin `spec-fuzz` selection and grounding workflow after measuring
the two-test property baseline on current main plus the issue-27 branch. Zero
Fuzz-kind obligations can be selected: no acceptance criterion authors a Fuzz
method, and Quoin 0.23.1 cannot obtain recommendations because its version probe
rejects the installed Quire 0.31.0 output. The active catalog was read directly
and confirms that Fuzz is the evidence kind for its fuzzing methods; that
catalog fact does not authorize choosing one for a requirement.

No fuzz target or workspace was created. The crate's public production entry
points accept typed `FormulaDocument` values and return typed reports; it owns
no byte/text parser or deserializer entry point. Guessing a serde wrapper or
fuzzing through the external parser would cross the stated crate boundary.

Renumbered from SR-049 when rebasing onto current `main`, whose own unrelated
work had since claimed that id (`agent-ix/tl-rewrite#27`). The rewrite
implementation this review scopes to (`src/rewrite.rs`) was itself split into
`src/engine/` by main's profile-separated rewrite architecture
(`agent-ix/tl-rewrite#42`) during the same rebase; the boundary finding below is
unaffected, since it concerns the crate's public typed API, not its internal
module layout.

These targets are **undischarged**. A fuzz target that has never run is a search
never started, and the evidence store will report it as such until a run is
recorded. In this run the target count is zero, so no fuzz-execution or fuzz-
coverage claim exists at all.

## Disposition

The issue-27 property baseline can merge independently. A later fuzz target
requires both a selected Fuzz-kind obligation and a repository-owned groundable
entry point (or an explicit owner decision to add one and scaffold a harness).
This review does not reinterpret typed graph properties as parser fuzzing, add a
local assurance adapter, scrape a fuzzer transcript, or infer correctness from
the absence of a crash.
