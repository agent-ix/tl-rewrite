# tl-rewrite deterministic transformation contract

## Component Boundary

The component begins with a validated formula and explicit catalog/options. It
ends with a typed report. Text parsing and downstream execution remain outside.

## Required Behavior

Stable rule order and budgets determine every result. Successful reports carry
a valid fixed-point formula and complete step chain. Bounded equivalence names
the exact enumerated domain and evaluator.

## Failure Handling

Schema/profile mismatch, budget exhaustion, graph growth, cycles, replay drift,
enumeration excess, and semantic mismatch are distinct non-success outcomes.

## Controls

Checked counters, deterministic logical work, graph interning, cycle digests,
exact dependency pins, strict schemas, corpus checksums, and independent replay
gate all exchanged claims.

## Replacement

A replacement must pass the same catalog, WEST subset, adversarial budgets,
replay, exhaustive bounded comparison, and retained evidence gates.
