# tl-rewrite deterministic transformation contract

## Component Boundary

The component begins with a validated formula and explicit rule catalog/options.
Contextual calls additionally begin with a shared signal catalog and optional
shared requirement context. It ends with a typed native report. Text parsing,
contract-IR translation, generic evidence retention, and downstream execution
remain outside.

## Required Behavior

Stable rule order and budgets determine every result. Successful reports carry
a valid fixed-point formula and complete step chain. Bounded equivalence names
the exact enumerated domain and evaluator. A contextual success additionally
binds the complete signal catalog, preserves exact caller context, and resolves
every surviving proposition through the unchanged catalog.

## Failure Handling

Schema/profile mismatch, budget exhaustion, graph growth, cycles, replay drift,
unresolved proposition bindings, enumeration excess, and semantic mismatch are
distinct non-success outcomes.

## Controls

Checked counters, deterministic logical work, graph interning, cycle digests,
exact dependency pins, strict schemas, corpus checksums, and independent replay
gate all exchanged claims.

## Replacement

A replacement must pass the same catalog, WEST subset, adversarial budgets,
replay, and exhaustive bounded comparison gates.
